A tiny reference for new players who want to clean and manage their harem. Copy-paste the examples.

$help
Sends the full command list to your DMs. Example: $help

$wa / $h / $m
Draw a Waifu, Husbando, or Both. Example: $wa

mmi / mml
Open your harem: mmi shows images, mml shows text/list. Example: $mmi

im / ima
Search character or series info. Example: $im Remilia

$top
Show the most wanted characters globally. Example: $top

$wish / $wishlist
Wish for a character or show your wishlist. Example: $wish Remilia / $wishlist

$like / $likelist
Like a character or show favorites. Example: $like Remilia / $likelist

$note [name]$[text]
Add a custom note for a character. No spaces around the $ separator. Example: $note Remilia$Check for duplicates

$divorce [name]
Remove a character from your harem. Example: $divorce Remilia

$rnl / $rnw
Rename list(s) — e.g., rename your harem or wishlist. Example: $rnl MyHarem

$sm
Sort by kakera (or other sort modes your bot supports). Example: $sm kakera
Note: original repo had $sm$mmk= which looks like a typo; confirm if there are flags you want documented.

$k / $kakera / $dailykakera / $dk / $daily
Rank up, check status, or collect daily kakera. Example: $daily

Short note: this file is intentionally minimal — just commands and examples so new players can start cleaning their harem quickly.
